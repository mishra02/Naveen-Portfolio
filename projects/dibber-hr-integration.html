Dibber — HR Integration Tool

Automated identity and account lifecycle workflows for a multinational kindergarten organization.

.NET Core Web APIAzure FunctionsAzure Active Directory / Microsoft Entra IDPowerShellSQL Server 2019On-premises Active DirectoryMicrosoft 365SSOMFAEpicor/Kinetic ERP

Project overview

The integration transfers HR and directory information from country-specific on-premises Active Directory environments and automates user lifecycle operations in Azure Active Directory. The organization operates across multiple countries; the stated goal was consistent account provisioning and access management for enterprise applications.

Public project URL: https://portal.azure.com/#home

My role and responsibilities

  • Held Global Administrator responsibilities across four country subscriptions, as stated in the resume.
  • Developed .NET Core Web API services for account automation.
  • Hosted APIs in Azure and triggered them on a schedule using Azure Function Apps.
  • Worked on database design and the software development lifecycle.
  • Supported synchronization with on-premises Active Directory.
  • Automated user creation, organizational-unit/group assignment, Microsoft 365 license assignment, and password communication to managers.
  • Supported user removal and account deactivation workflows.
  • Supported SSO and MFA enablement for enterprise applications.

Capabilities and contribution

  • Reduced manual effort in user provisioning and lifecycle management.
  • Supported consistent access administration across country environments.
  • Connected HR/directory processes with cloud identity services.
